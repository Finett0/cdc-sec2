# sec2 - Security Solutions Landing Page

A modern, responsive landing page for sec2 security solutions built with Next.js, React, and Tailwind CSS.

## Features

- 🚀 **Next.js 14** with App Router
- ⚛️ **React 18** with TypeScript
- 🎨 **Tailwind CSS** for styling
- 📱 **Fully Responsive** design
- 🎯 **SEO Optimized** with proper meta tags
- 🚀 **Vercel Ready** for deployment
- 💜 **Modern UI** with smooth animations and hover effects

## Sections

- **Header**: Navigation with mobile menu
- **Hero**: Main headline and call-to-action
- **Security Concerns**: Two-column layout highlighting security issues
- **DevSecOps**: Feature cards showcasing benefits
- **Content**: Article/blog section
- **Footer**: Enhanced with social media icons and contact information

## Getting Started

1. Install dependencies:
```bash
npm install
```

2. Run the development server:
```bash
npm run dev
```

3. Open [http://localhost:3000](http://localhost:3000) in your browser.

## Deployment

This project is optimized for Vercel deployment. Simply connect your GitHub repository to Vercel and deploy.

## Technologies Used
